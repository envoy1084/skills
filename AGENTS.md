# envoy1084/skills

Agent skills installed with `npx skills add envoy1084/skills`:

- `skills/`: own skills, in the [Agent Skills](https://agentskills.io) format.
- `vendor/<collection>/skills/`: external skills copied unchanged at a pinned commit. Generated by
  `pnpm sync` from `vendor/vendor.json`; never edit `vendor/` by hand.
- `.claude-plugin/marketplace.json`: the same skills as Claude Code plugins (external entries are
  written by `pnpm sync`).
- `global/AGENTS.md`: a backup of the user's global agent instructions.
- `tools/cli`: `skills-dev` (`pnpm sync`, `pnpm report`), written with Effect v4. Before changing
  it, read `node_modules/effect/AGENTS.md` and follow the `effect-conventions`
  skill.

Rules:

- When the user installs or removes skills globally, or edits their global AGENTS.md, follow
  `.agents/skills/sync-skills/SKILL.md`.
- Run `pnpm check` before committing. `pnpm format` formats only the tooling files; skill Markdown
  and the scaffold templates are not reformatted.
- Test a changed skill on a throwaway project before committing.
- Never push without being asked.
